# Q52. Cloud Kicks社の管理者が、新しいクラウドシューズの返品を追跡するための…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice52

## 問題

Cloud Kicks社の管理者が、新しいクラウドシューズの返品を追跡するための新しい項目を作成しました。あるユーザーが、新しい項目が利用できない旨のケースを管理者に提出しました。この問題をトラブルシューティングするために管理者が行うべきステップはどれですか。2つ選びなさい。

## 選択肢

- ユーザーのプロファイルのページレイアウトが更新されていることを確認する。
- 組織の[設定変更履歴の参照]を確認する。
- オブジェクトの組織全体のデフォルトを更新する。
- ユーザーのプロファイルにおいて項目レベルセキュリティを確認する。

## 正解（2つ選択）

> **ユーザーのプロファイルのページレイアウトが更新されていることを確認する。**
> **ユーザーのプロファイルにおいて項目レベルセキュリティを確認する。**

## 解説

それぞれの選択肢の理由について説明します。

□ ユーザーのプロファイルのページレイアウトが更新されていることを確認する。これは正解です。新しい項目がページレイアウトに追加されていない場合、ユーザーはその項目を表示できません。ページレイアウトを更新して新しい項目が表示されるようにすることは、一般的なトラブルシューティングのステップです。

□ 組織の[設定変更履歴の参照]を確認する。これは不正解です。[設定変更履歴の参照]は、組織内で行われた設定変更を確認するためのツールですが、具体的な項目の表示問題のトラブルシューティングには直接関係ありません。

□ オブジェクトの組織全体のデフォルトを更新する。これは不正解です。組織全体のデフォルト設定は、レコードのアクセスレベルを制御するものであり、特定の項目が表示されない問題には直接影響しません。

□ ユーザーのプロファイルにおいて項目レベルセキュリティを確認する。これは正解です。項目レベルセキュリティを確認し、新しい項目がユーザーのプロファイルで適切に設定されていることを確認することは重要です。項目レベルセキュリティが正しく設定されていない場合、ユーザーは項目を表示または編集することができません。
