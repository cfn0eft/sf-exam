# Q55. Cloud Kicks社のユーザーは、2週間ごとに繰り返すToDoを作成できるよ…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice55

## 問題

Cloud Kicks社のユーザーは、2週間ごとに繰り返すToDoを作成できるようにしたいと考えています。この要求を満たすために、管理者は何をすべきでしょうか。

## 選択肢

- 繰り返しToDoの作成を有効にする。
- 繰り返しToDoを作成するフローを作成する。
- 繰り返しToDoを作成するワークフロールールを作成する。
- 定期的な活動を有効にする。

## 正解

> **繰り返しToDoの作成を有効にする。**

## 解説

それぞれの選択肢の理由について説明します。

□ 繰り返しToDoの作成を有効にする。これは正解です。Salesforceには繰り返しToDoの機能があり、これを有効にすることでユーザーは特定の頻度で繰り返されるToDoを作成できます。2週間ごとに繰り返すToDoもこの機能を使用して設定することができます。

□ 繰り返しToDoを作成するフローを作成する。これは不正解です。フローを使用して繰り返しToDoを作成することはできますが、Salesforceの標準機能である繰り返しToDoを有効にする方が簡単かつ効率的です。

□ 繰り返しToDoを作成するワークフロールールを作成する。これは不正解です。ワークフロールールは自動化されたアクションをトリガーするために使用されますが、繰り返しToDoを直接作成するための機能は提供していません。

□ 定期的な行動を有効にするこれは不正解です。定期的な行動は、Salesforce Classicで行動(イベントや会議)の繰り返しを設定するもので、ToDo(タスク)には適用されません。今回の要件はToDoの繰り返しであり、この設定では実現できません。
