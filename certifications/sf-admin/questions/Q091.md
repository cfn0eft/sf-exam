# Q91. Cloud Kicks社の管理者が、特定の条件を満たすレコードを検索し、それらの…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice91

## 問題

Cloud Kicks社の管理者が、特定の条件を満たすレコードを検索し、それらのレコードの値を後でフローで使用するために変数に格納する必要があるフローを構築しています。管理者はどのフロー要素を追加すべきですか。

## 選択肢

- 割り当て
- レコードを取得
- レコードを作成
- レコードを更新

## 正解

> **レコードを取得**

## 解説

それぞれの選択肢の理由について説明します。

□ 割り当てこれは不正解です。割り当て要素は、変数やコレクション変数に値を設定するために使用されますが、レコードの検索や値の取得には使われません。

□ レコードを取得これは正解です。この要素は条件に基づいてレコードを検索し、その結果を変数に保存するために使用されます。これにより、後続のフロー部分でそのデータを参照または操作できるようになります。

□ レコードを作成これは不正解です。レコードを作成する要素は、新しいレコードをSalesforceに作成する際に使用され、既存のレコードを検索するためのものではありません。

□ レコードを更新これは不正解です。レコードを更新する要素は、既存のレコードの項目を変更する際に使用されます。この要素は、レコードの検索やそのデータを変数に保存するためには使われません。
