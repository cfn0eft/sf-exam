# Q69. Cloud Kicks社は、2月1日に始まり12ヶ月を有する会計年度をレポートに…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice69

## 問題

Cloud Kicks社は、2月1日に始まり12ヶ月を有する会計年度をレポートに表示させたいと考えています。管理者はこの要件にどのように対処すべきでしょうか。

## 選択肢

- 会計年度を[標準]に設定し、期間を12ヶ月に設定する。
- 会計年度を[カスタム]に設定し、期間を4四半期に設定する。
- 会計年度を[標準]に設定し、開始月を2月に設定する。
- 会計年度を[カスタム]に設定し、開始月を2月に設定する。

## 正解

> **会計年度を[標準]に設定し、開始月を2月に設定する。**

## 解説

それぞれの選択肢の理由について説明します。

□ 会計年度を[標準]に設定し、期間を12ヶ月に設定する。これは不正解です。標準会計年度では開始月を変更することはできますが、期間を12ヶ月に設定するというオプションはありません。

□ 会計年度を[カスタム]に設定し、期間を4四半期に設定する。これは不正解です。カスタム会計年度は柔軟な設定が可能ですが、標準会計年度で開始月を2月に設定できるため、複雑なカスタム会計年度を設定する必要はありません。また、カスタム会計年度は一度有効にすると無効にできないため、標準で設定できる場合には不要です。

□ 会計年度を[標準]に設定し、開始月を2月に設定する。これは正解です。標準会計年度では、開始月を任意の月に設定することができます。開始月を2月に設定することで、2月1日から始まる会計年度を設定でき、Cloud Kicks社の要件を満たすことができます。

□ 会計年度を[カスタム]に設定し、開始月を2月に設定する。これは不正解です。カスタム会計年度は標準会計年度で開始月を2月に設定できる場合には不要です。さらに、カスタム会計年度は一度有効にすると無効にできないため、標準会計年度で対応できるならカスタム会計年度を使用する必要はありません。
