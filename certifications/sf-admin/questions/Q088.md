# Q88. Cloud Kicks社では、公開されているホームページにアクセスしながら、顧客…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice88

## 問題

Cloud Kicks社では、公開されているホームページにアクセスしながら、顧客が自分のケースを作成できるようにしたいと考えています。管理者は何を推奨すべきでしょうか。

## 選択肢

- SMS 送信
- Web-to-ケース
- メール-to-ケース
- オムニチャネル

## 正解

> **Web-to-ケース**

## 解説

それぞれの選択肢の理由について説明します。

□ SMS 送信これは不正解です。SMS送信は顧客へのメッセージングツールであり、ホームページから顧客が自分でケースを作成する機能ではありません。SMSは主に顧客とのコミュニケーションやマーケティングキャンペーンに使用され、ケース作成には関係しません。

□ Web-to-ケースこれは正解です。Web-to-ケースは、顧客がWebフォームを通じてケースを作成できるSalesforceの機能です。公開されているホームページにWeb-to-ケースフォームを設置することで、顧客は直接自分のケースを作成することができます。この方法は、簡単に設定でき、顧客が自分の問題や問い合わせを簡単に報告できるようにするために最適です。

□ メール-to-ケースこれは不正解です。メール-to-ケースは、顧客がメールを送信することでケースを作成する機能です。この機能は、顧客がホームページ上で直接ケースを作成する方法としては適していません。

□ オムニチャネルこれは不正解です。オムニチャネルは、エージェントに作業項目を自動で割り当てるSalesforceの機能です。直接的にホームページ上でケースを作成する機能ではありません。
