# Q92. Cloud Kicks社のカスタマーサクセス担当者が休暇に入り、複数のケースの所…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice92

## 問題

Cloud Kicks社のカスタマーサクセス担当者が休暇に入り、複数のケースの所有者を変更する必要があります。この要求を満たすことができるのはどのユーザーですか。2つ選びなさい。

## 選択肢

- 取引先に参照権限を持つユーザー
- 担当者より上のマネージャーロールを持つユーザー
- システム管理者プロファイルを持つユーザー
- ケースの管理権限を持つユーザー

## 正解（2つ選択）

> **担当者より上のマネージャーロールを持つユーザー**
> **システム管理者プロファイルを持つユーザー**

## 解説

それぞれの選択肢の理由について説明します。

□ 取引先に参照権限を持つユーザーこれは不正解です。参照権限のみでは、レコードの所有権を変更することはできません。所有権の変更には、さらに高いレベルの権限が必要です。

□ 担当者より上のマネージャーロールを持つユーザーこれは正解です。ロール階層で担当者より上位に位置するユーザーは、レコードの所有権を変更する権限を持っています。取引先所有者より上位に位置するユーザーには、取引先や関連するケースの所有権を変更する権限があります。

□ システム管理者プロファイルを持つユーザーこれは正解です。システム管理者は全組織にわたる全てのレコードにアクセスできる最高権限を持っており、どのレコードの所有者でも変更することができます。

□ ケースの管理権限を持つユーザーこれは不正解です。ケースの管理権限を持つユーザーは、ケースの参照、作成、編集、削除が可能ですが、所有権の変更を行うためには、取引先に対する「すべて変更」権限や、取引先所有者より上位のロールにいることが必要です。
