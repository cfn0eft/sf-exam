# Q76. Cloud Kicks社の管理者は、顧客が電話で問題を問い合わせたときにサービス…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice76

## 問題

Cloud Kicks社の管理者は、顧客が電話で問題を問い合わせたときにサービス担当者が同じ質問をするのに役立つ画面フローを作成しました。この画面はケースから見えるようにする必要があります。画面フローはどのように配置する必要がありますか。

## 選択肢

- Lightning ページ
- ページレイアウト
- ホームページ
- コンポーネントの表示を設定

## 正解

> **Lightning ページ**

## 解説

それぞれの選択肢の理由について説明します。

□ Lightning ページこれは正解です。Lightning ページに画面フローを配置することで、ケースレコードページにフローを表示できます。Lightning アプリケーションビルダーを使用して、フローコンポーネントをケースレコードページに追加することができます。これにより、サービス担当者はケース詳細ページから直接画面フローを利用することができます。

□ ページレイアウトこれは不正解です。ページレイアウトは、レコードページ上の項目や関連リストの表示を制御するためのもので、画面フローを直接追加することはできません。

□ ホームページこれは不正解です。ホームページに画面フローを配置すると、Salesforceのホームページ上にフローが表示されますが、特定のケースレコードと関連付けられたフローを表示するには適していません。ケースに関連した操作を行うためには、ケースレコードページにフローを配置する必要があります。

□ コンポーネントの表示を設定これは不正解です。コンポーネントの表示を設定することは、コンポーネントの表示条件を設定するためのもので、画面フローをどこに配置するかを決定するものではありません。
