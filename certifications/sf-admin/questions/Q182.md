# Q182. Cloud Kicks社の管理者は、カスタマーサービスチームが顧客の問い合わせ…

**URL:** https://help.salesforce.com/s/articleView?id=sf.agentforce_overview.htm

## 問題

Cloud Kicks社の管理者は、カスタマーサービスチームが顧客の問い合わせに24時間対応できるように、自律的に会話できるAIエージェントを導入したいと考えています。管理者はどの機能を使用すべきでしょうか。

## 選択肢

- フロービルダーでスクリーンフローを作成する。
- Agentforceのサービスエージェントを設定する。
- Einstein ボットを新規作成する。
- ケースの自動割り当てルールを設定する。

## 正解

> **Agentforceのサービスエージェントを設定する。**

## 解説

それぞれの選択肢の理由について説明します。

□ フロービルダーでスクリーンフローを作成する。これは不正解です。スクリーンフローはユーザーがSalesforce内で操作するガイド付きプロセスを作成するためのツールです。顧客が自律的に会話できるAIエージェントとしての機能は持っていません。

□ Agentforceのサービスエージェントを設定する。これは正解です。Agentforceのサービスエージェントは、大規模言語モデル（LLM）を活用して顧客の問い合わせに自律的に対応できるAIエージェントです。事前定義されたトピックとアクションに基づき、人間の担当者なしに24時間顧客対応が可能です。

□ Einstein ボットを新規作成する。これは不正解です。Einstein ボットはルールベースの従来型チャットボットで、Agentforceのような大規模言語モデルを使用した自律的な会話能力は持っていません。現在SalesforceはAgentforceへの移行を推奨しています。

□ ケースの自動割り当てルールを設定する。これは不正解です。自動割り当てルールはケースを適切なキューや担当者に振り分けるためのルールです。AIによる自律的な顧客対応の機能はありません。

参考：Agentforce の概要
