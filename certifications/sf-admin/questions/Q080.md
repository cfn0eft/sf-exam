# Q80. Cloud Kicks社の管理者が、過去90日間のクローズした商談のファイルをエ…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice80

## 問題

Cloud Kicks社の管理者が、過去90日間のクローズした商談のファイルをエクスポートする必要があります。このファイルには、商談名、ID、完了予定日、および金額が含まれている必要があります。管理者はこのファイルをどのようにエクスポートしますか。

## 選択肢

- データインポートウィザード
- データローダー
- データエクスポートウィザード
- マンスリーエクスポートサービス

## 正解

> **データローダー**

## 解説

それぞれの選択肢の理由について説明します。

□ データインポートウィザードこれは不正解です。 データインポートウィザードは、データをSalesforceにインポートするためのツールであり、エクスポート機能は提供していません。

□ データローダーこれは正解です。 データローダーは特定のクエリ条件に基づいてSalesforceからデータをエクスポートするために適したツールです。管理者は過去90日間にクローズした商談のような特定のデータセットを選択し、必要な項目(商談名、ID、完了予定日、金額)を含むファイルをエクスポートできます。

□ データエクスポートウィザードこれは不正解です。 Salesforceには[データエクスポートウィザード]という名称の機能は存在しません。

□ マンスリーエクスポートサービスこれは不正解です。 マンスリーエクスポートサービスは組織データの定期的なバックアップを提供しますが、特定の商談データを条件付きでエクスポートする機能はありません。
