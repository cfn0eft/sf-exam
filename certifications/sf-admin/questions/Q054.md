# Q54. Cloud Kicks社の役員は、商談オブジェクトの期待収益項目が正しくない値を…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice54

## 問題

Cloud Kicks社の役員は、商談オブジェクトの期待収益項目が正しくない値を表示していることに気づきました。管理者はどのようにこれを修正する必要がありますか。

## 選択肢

- フェーズに関連付けられている[期待収益]項目を更新する。
- フェーズに関連付けられている[売上予測分類]項目を調整する。
- フェーズに関連付けられている[確度 (%)]項目を変更する。
- フェーズに関連付けられているClosed Wonの値を変更する。

## 正解

> **フェーズに関連付けられている[確度 (%)]項目を変更する。**

## 解説

それぞれの選択肢の理由について説明します。

□ フェーズに関連付けられている[期待収益]項目を更新する。これは不正解です。期待収益は、商談の金額と確度を基に自動計算される項目です。この値は直接更新はできません。

□ フェーズに関連付けられている[売上予測分類]項目を調整する。これは不正解です。[売上予測分類]項目は、商談がどの予測カテゴリに属するかを決定し、レポート、商談の詳細および編集のページ、商談の検索、商談リストビューに表示されますが、[期待収益]の値には直接影響を与えません。

□ フェーズに関連付けられている[確度 (%)]項目を変更する。これは正解です。期待収益の計算は、商談の金額とその商談のフェーズに関連する確度 (%)に基づいています。フェーズに関連する確度のパーセンテージを変更することで、期待収益の計算に影響を与え、不正確な値を修正することができます。

□ フェーズに関連付けられているClosed Wonの値を変更する。これは不正解です。Closed Wonの値は、商談が成功したことを示すフェーズですが、期待収益の計算には直接関与しません。期待収益は、商談がまだクローズされていない段階での確度に基づく金額の算出に関連しているため、この値を変更しても期待収益の計算には影響しません。
