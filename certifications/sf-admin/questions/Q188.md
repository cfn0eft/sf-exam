# Q188. Cloud Kicks社の管理者は、Agentforceエージェントが扱うべきでない…

**URL:** https://help.salesforce.com/s/articleView?id=sf.agentforce_topics.htm

## 問題

Cloud Kicks社の管理者は、Agentforceエージェントが扱うべきでない話題（例：競合他社の情報や政治的な話題）について応答しないようにしたいと考えています。管理者はどのように設定すべきでしょうか。

## 選択肢

- エージェントを無効化して、対象外の話題が来たら手動で対応する。
- Agent Builderのシステムプロンプト（エージェントの指示）に、対応しない話題の制限を記述する。
- フロービルダーでキーワードフィルタを作成する。
- プロファイルでエージェントの権限を制限する。

## 正解

> **Agent Builderのシステムプロンプト（エージェントの指示）に、対応しない話題の制限を記述する。**

## 解説

それぞれの選択肢の理由について説明します。

□ エージェントを無効化して、対象外の話題が来たら手動で対応する。これは不正解です。エージェントを無効化するとすべての機能が失われます。特定話題への制限を設けながら他の機能を維持するためのアプローチではありません。

□ Agent Builderのシステムプロンプト（エージェントの指示）に、対応しない話題の制限を記述する。これは正解です。Agent Builderでは、エージェント全体の動作方針を定める「エージェントの指示（Agent Instructions）」を設定できます。ここに「競合他社の情報や政治的な話題には応答しないこと」のような制限を自然言語で記述することで、エージェントの応答範囲をコントロールできます。これはAgentforceの責任あるAI利用において重要な設定です。

□ フロービルダーでキーワードフィルタを作成する。これは不正解です。フロービルダーにはAgentforceの会話を傍受してキーワードフィルタをかける機能はありません。エージェントの動作制限はAgent Builder内の指示で行います。

□ プロファイルでエージェントの権限を制限する。これは不正解です。プロファイルはデータアクセスを制限するものです。エージェントが応答する話題の範囲を制御することはできません。
