# Q62. Cloud Kicks社はデータエクスポートサービスを利用してバックアップでデー…

**URL:** https://tysonblog-whitelabel.com/salesforce-admin-practice62

## 問題

Cloud Kicks社はデータエクスポートサービスを利用してバックアップでデータを保護しようとしています。管理者がエクスポートのスケジュールを立てる際に覚えておくべき考慮事項はどれですか。2つ選びなさい。

## 選択肢

- メタデータのバックアップは別のプロセスで実行する必要があります。
- メタデータのバックアップは、Sandboxの更新間隔に制限されています。
- データエクスポートサービスはサンドボックスから実行する必要があります。
- データのバックアップは毎週または毎月の間隔に制限されます。

## 正解（2つ選択）

> **メタデータのバックアップは別のプロセスで実行する必要があります。**
> **データのバックアップは毎週または毎月の間隔に制限されます。**

## 解説

それぞれの選択肢の理由について説明します。

□ メタデータのバックアップは別のプロセスで実行する必要があります。これは正解です。データエクスポートサービスはデータのバックアップに特化しており、メタデータのバックアップには対応していません。メタデータのバックアップは未管理パッケージの作成や、メタデータAPIを使用して実行する必要があります。

□ メタデータのバックアップは、Sandboxの更新間隔に制限されています。これは不正解です。メタデータのバックアップはSandboxの更新間隔には影響されません。メタデータのバックアップはいつでも実行可能です。

□ データエクスポートサービスはサンドボックスから実行する必要があります。これは不正解です。データエクスポートサービスは本番環境で使用されることを想定しています。サンドボックス環境からのエクスポートはサポートされていません。

□ データのバックアップは毎週または毎月の間隔に制限されます。これは正解です。Salesforceのデータエクスポートサービスは、エクスポートのスケジュールを毎週または毎月に設定することができます。エクスポートの頻度は、ユーザーの選択に基づいて設定されます。
