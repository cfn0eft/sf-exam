# Q186. Universal Containers社の管理者は、Agentforceを使用して…

**URL:** https://help.salesforce.com/s/articleView?id=sf.agentforce_prompt_builder.htm

## 問題

Universal Containers社の管理者は、AgentforceエージェントがSalesforceのデータを参照して、一貫したトーンと形式でメールを生成するテンプレートを作成したいと考えています。管理者はどの機能を使用すべきでしょうか。

## 選択肢

- メールテンプレートを作成する。
- Prompt Builderでプロンプトテンプレートを作成する。
- フロービルダーでメール送信アクションを設定する。
- Einstein Activity Captureを有効化する。

## 正解

> **Prompt Builderでプロンプトテンプレートを作成する。**

## 解説

それぞれの選択肢の理由について説明します。

□ メールテンプレートを作成する。これは不正解です。従来のメールテンプレートは静的なHTMLやテキストのテンプレートです。AIによる動的なコンテンツ生成やSalesforceデータのグラウンディング（参照）には対応していません。

□ Prompt Builderでプロンプトテンプレートを作成する。これは正解です。Prompt Builderは、Salesforceのレコードデータを参照（グラウンディング）しながらAIが生成するコンテンツのテンプレートを作成できる機能です。「項目生成」や「フレックス」などのテンプレートタイプがあり、Agentforceや項目値の自動生成に活用されます。管理者はここでプロンプトのテキスト、参照するオブジェクト・項目、AIモデルを設定できます。

□ フロービルダーでメール送信アクションを設定する。これは不正解です。フローのメール送信アクションは定型文のメールを送信するためのものです。AIが動的にコンテンツを生成する機能はありません。

□ Einstein Activity Captureを有効化する。これは不正解です。Einstein Activity CaptureはメールやカレンダーをSalesforceに自動同期する機能です。プロンプトテンプレートの作成とは無関係です。
