# Salesforce 設定画面ナビゲーションマップ

> 「この機能はどこにある？」を逆引きするための設定画面インデックス  
> 最終更新: 2026-05-24

---

## 使い方

- 問題文に「管理者が設定する」「どこで有効化するか」という問いが出たら、このマップで設定画面を確認する
- 各エントリの `→ study_guide` リンクで定義・試験ポイントを参照する

---

## オブジェクトマネージャ

`[設定] > [オブジェクトマネージャ] > {オブジェクト名}`

| サブメニュー | 機能 | study_guide |
|---|---|---|
| 項目と関連 > [新規] | カスタム項目作成（テキスト・数値・選択リスト・参照関係など） | — |
| 項目と関連 > 項目名 > [履歴の追跡] | 項目履歴の追跡（変更ログ） | [項目履歴の追跡](#項目履歴の追跡field-history-tracking) |
| **入力規則** | 保存時のデータ検証ルール | [入力規則](study_guide.md#入力規則validation-rule) |
| ページレイアウト | 項目・ボタン・関連リストの配置 | [ページレイアウト](study_guide.md#ページレイアウト) |
| コンパクトレイアウト | ハイライトパネルに表示する項目 | [コンパクトレイアウト](study_guide.md#コンパクトレイアウト) |
| レコードタイプ | ビジネスプロセス・選択リスト・ページレイアウトの使い分け | [レコードタイプ](study_guide.md#レコードタイプ) |
| 積み上げ集計項目 | 主従関係の子レコード集計 | [積み上げ集計項目](study_guide.md#積み上げ集計項目roll-up-summary) |
| リード変換の対応付け | リード変換時の項目マッピング | [リード変換と項目対応付け](study_guide.md#リード変換と項目対応付けlead-conversion-mapping) |

> **よく出るオブジェクト**: 商談（Opportunity）・リード（Lead）・ケース（Case）・取引先（Account）・カスタムオブジェクト

## プロセスの自動化

`[設定] > [プロセスの自動化]`

| メニュー | 機能 | 出題傾向 | study_guide |
|---|---|---|---|
| **フロー** | フロービルダー（現在の主要自動化ツール） | ◎ 最頻出 | [フロービルダー](study_guide.md#フロービルダーflow-builder) |
| プロセスビルダー | 旧来の if-then 自動化（廃止予定・非推奨） | △ 低（廃止予定） | [プロセスビルダー](study_guide.md#プロセスビルダーprocess-builder) |
| ワークフロールール | 旧来の単純自動化（廃止予定・非推奨） | △ 低（廃止予定） | — |
| 承認プロセス | 多段階の承認フロー | ○ 中程度 | [承認プロセス](study_guide.md#承認プロセスapproval-process) |
| パス設定 | レコードの進捗パス表示 | ○ 中程度 | [パス](study_guide.md#パスsalesforce-path) |

> **廃止予定ツールの試験対策**: ワークフロールール・プロセスビルダーは「フロービルダーで代替できる」という文脈で出題される。自分で新規作成する選択肢としては誤り。

## 出題傾向ランキング（設定画面別）

| 順位 | 設定画面 | 代表的な機能 |
|---|---|---|
| ◎ 最頻出 | オブジェクトマネージャ | 入力規則・ページレイアウト・レコードタイプ・項目設計 |
| ◎ 最頻出 | プロセスの自動化 > フロー | フロービルダー（画面フロー・レコードトリガー） |
| ○ 頻出 | ユーザー > プロファイル | オブジェクト権限・FLS・ページレイアウト割り当て |
| ○ 頻出 | サービス > 割り当てルール | ケース・リードの自動担当者割り当て |
| ○ 頻出 | セキュリティ > パスワードポリシー | 試行回数・有効期限・強制リセット |
| △ 低 | プロセスの自動化 > プロセスビルダー | 廃止予定（「代替はフロー」として出題） |
| △ 低 | プロセスの自動化 > ワークフロールール | 廃止予定（「代替はフロー」として出題） |

## Agentforce

`[設定] > [Agentforce エージェント]`

| メニュー / 操作 | 機能 | study_guide |
|---|---|---|
| **Agentforce エージェント** | エージェント一覧・新規作成・有効化/無効化 | [Agentforceとは](study_guide.md#agentforceとは) |
| Agent Builder > **エージェントの指示** | エージェント全体の動作方針・応答禁止事項を自然言語で定義 | [Agent Builder](study_guide.md#agent-builderエージェント設定ツール) |
| Agent Builder > **トピック** | 業務領域の定義と指示（Instructions）の設定 | [トピックとアクション](study_guide.md#トピックとアクション試験頻出) |
| Agent Builder > **アクション** | フロー・Apex・標準アクションをエージェントに追加 | [トピックとアクション](study_guide.md#トピックとアクション試験頻出) |
| Agent Builder > **会話プレビュー** | 本番リリース前の会話シミュレーションテスト | [会話プレビュー](study_guide.md#会話プレビューテスト機能) |
| Agent Builder > **チャネル** | Webチャット・SMS・WhatsApp等への接続設定 | [対応チャネル](study_guide.md#対応チャネル) |

`[設定] > [Einstein] > [Prompt Builder]`

| メニュー / 操作 | 機能 | study_guide |
|---|---|---|
| **Prompt Builder** | プロンプトテンプレートの作成・管理（項目生成・フレックス・セールスメール） | [Prompt Builder](study_guide.md#prompt-builderプロンプトテンプレート) |

> **エージェントユーザーの権限確認場所**：`[設定] > [ユーザー]` でエージェントユーザーを検索 → プロファイルと権限セットを確認

> **試験対策メモ**：Agentforceの設定は主に **Agent Builder** で行う。権限問題は **エージェントユーザー** のプロファイル・権限セットで解決する。
